# Datasets

Raw training data lives here and is **gitignored** except this README.

## What to download (Phase 4)

Use [Google Cluster Workload Traces 2019](https://github.com/google/cluster-data) — **sample shards only**, not the full ~2.4 TiB dump.

Recommended minimum:

```text
datasets/google-cluster-2019/cell_a/
  instance_events-000000000000.json.gz
  instance_usage-000000000000.json.gz
```

Browser links (cell `a`, shard `0`):

- https://storage.googleapis.com/clusterdata_2019_a/instance_events-000000000000.json.gz
- https://storage.googleapis.com/clusterdata_2019_a/instance_usage-000000000000.json.gz

`instance_events` provides requested CPU/memory. `instance_usage` provides average (and maximum) usage.

These files are **training data only**. Users never upload them to the API.

## Processed output

Generated by `python ml/preprocess.py`:

```text
datasets/processed/train.csv
datasets/processed/test.csv
datasets/processed/metadata.json
```

See [ml/README.md](../ml/README.md) for how to run preprocessing and how columns map to the Phase 3 feature schema.

## Do not commit

- Raw `.json.gz` shards
- Processed CSVs
- Trained `.pkl` / `.joblib` models
